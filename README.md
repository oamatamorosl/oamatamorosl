## Proyectos

### 🥋 [Perro Loco](https://github.com/oamatamorosl/perroloco)
Sistema de gestión para una academia de artes marciales mixtas, construido en **Django** con **PostgreSQL**.

- Autenticación personalizada por número de teléfono en lugar de usuario tradicional
- Panel de alumno con horarios semanales y registro de asistencia
- Panel de profesor para aprobar asistencias, registrar pagos y administrar cuentas bancarias
- Control automático del estado de membresía (activo, por vencer, vencido) según la fecha de pago
- Historial de peleas por modalidad y resultado, y sistema de cinturones por alumno
- Configuración lista para despliegue con Gunicorn y WhiteNoise

### 💼 [Camella EC](https://github.com/adriangbustos/Camella-EC)
Plataforma web que conecta trabajadores y contratantes en Ecuador. Construida en **Angular 17** con **Firebase** para autenticación y datos, integra mapas con **Leaflet** para ubicar ofertas por zona y maneja dos flujos independientes: uno para quienes buscan empleo y otro para quienes contratan, con onboarding, validación de perfiles y postulaciones.

> Colaboración en equipo — repositorio principal a cargo de [@adriangbustos](https://github.com/adriangbustos)
